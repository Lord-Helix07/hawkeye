## Police Drone Frontend

React + Vite prototype for a police drone pursuit interface. The app includes fake pursuit data, recorded dashcam video, YOLO11-style simulated vehicle lock, backend-ready action buttons, and a fake drone location map.

## Requirements

- Node.js
- npm

The required frontend packages are listed in `package.json` and locked in `package-lock.json`.

## Run Locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal, usually `http://localhost:5173/`.

## Build

```bash
npm run build
```

## Release

The first release packages the current Police Drone frontend prototype for project review and testing.
